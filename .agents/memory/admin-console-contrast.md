---
name: Admin console contrast
description: User requirement for readable, editable event controls in this app.
---

Keep the volunteer/admin console high-contrast and make event management controls available there rather than leaving them display-only.

**Why:** The user said the existing admin palette was unreadable and asked for the event to be editable from the admin and volunteer side. They explicitly chose separate volunteer accounts with full operational editing, and random routes based on the registered team roster.

**How to apply:** Keep dark admin cards paired with light text and light panels paired with dark text. Volunteers may use all event operations, including reset/delete and event controls; only administrators manage volunteer accounts. Generate random routes for all registered teams at event start and balance their first checkpoints across active stops.
