---
name: Admin console contrast
description: User requirement for readable, editable event controls in this app.
---

Keep the volunteer/admin console high-contrast and make event management controls available there rather than leaving them display-only.

**Why:** The user said the existing admin palette was unreadable and asked for the event to be editable from the admin and volunteer side.

**How to apply:** Keep dark admin cards paired with light text and light panels paired with dark text. When auditing editability, check checkpoints, teams, event settings, and route controls; ask before granting destructive permissions to new roles.
